# Deltas historiques C20 avant reprise ACSM

Les sept fichiers sont conservés intégralement, octet pour octet. Le contrôle préalable et leurs empreintes figurent dans [COUVERTURE_DELTAS_ACSM.md](../COUVERTURE_DELTAS_ACSM.md).

Ils constituent une trace des décisions et versions antérieures, hors des deltas normatifs actifs. Les 34 exigences déjà au canon et le modèle de modes remplacé ne doivent pas être réappliqués. Les deux exigences Nuitka encore proposées sont maintenues séparément dans le [delta actif reference-runtime](../specs/reference-runtime/spec.md), avec leurs six scénarios et leurs tâches futures. Ce rangement ne termine ni tâche, ni qualification, ni réalisation.

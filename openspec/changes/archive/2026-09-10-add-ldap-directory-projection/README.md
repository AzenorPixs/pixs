# add-ldap-directory-projection — cadrage architectural initial

## Statut

Le 10 septembre 2026, ce changement a été requalifié par le développeur comme
une exigence du périmètre architectural initial de Pixs. Les spécifications
actives constituent la source de vérité de ce cadrage.

Aucun provider LDAP, endpoint, dépendance, credential ni implémentation de
projection n'est livré par cette requalification.

## Tâches conservées

Les tâches de `tasks.md` sont volontairement conservées non réalisées. Elles
décrivent le travail d'implémentation futur et ne constituent pas une preuve de
livraison.

Toute implémentation devra faire l'objet d'un nouveau changement OpenSpec,
incluant le code, les tests de conformité et les validations applicables.
